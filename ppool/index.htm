Features

Tournament-sized Table

The table size simulates a tournament setting, with the inner table mat sized to 100 inches by 50 inches (or 2.54 meters by 1.27 meters).

Practice shots

The included Practice mode allows for setting up your own layouts and shooting. There is also a rudimentary aiming aid systemm, available for all modes. Nearly half of the supported games have solo play support also.

Multiple ways to play

Nearly a dozen different games are pre-packed with Physics Pool. Eight Ball, Nine Ball, Cutthroat, to name a few... Nearly half of the supported games are adapted for 2 or 3-player play.
