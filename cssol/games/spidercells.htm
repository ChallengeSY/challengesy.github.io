Instructions

The object of SpiderCells is to assemble a set of 4 King-Ace builds in the tableau.

Tableau piles are built down by alternating colors. There are a set of 4 reserve slots, each of which can hold one card. Builds of cards can be moved. Empty spaces can be filled with any card.
